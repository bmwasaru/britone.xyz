For the next months, my college classmates and I will be working on creating a mobile web app. The details are supposed to be secret, we decided to create the app after attending the Firefox OS Apps Day (refer to previous post).
Why the secrecy? We want to surprise especially our classmates. There is a culture where my fellow students are not doing anything else but reading for their exams, which is really bad for the technology sector. I'm a believer that a first honors degree will not help that much if you do not have the skills of creating something from scratch, solving problems as they emerge and having the drive to learn on your own. We are not that good in programming heck we are just beginners.It's all about curiosity and the feeling as we see how ideas are convert into something that really works.
How are going to actually create the app?

1. Identified the single problem we are solving.
2. We have researched on what programming languages we will need to write the app.
3. Sketched the User Interface on paper.
4. Now the actual development but there is a single detail we are going on a semester break which means guys are going back home and we live in different parts of the country, we decided to use Dropbox and share our codes and constant communication on what needs to be done.
5. We will be learning on the go that is identify what is needed, research on how it can be done then code it. Rather than read a whole programming language then code the app. This will be faster and we can actually have something within a short period of time.

I'm excited :)
